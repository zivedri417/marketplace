every user has a homepage, which is the user profile page.

when a user is created, the user is assigned to a homepage.

the homepage is public for everyone to view, and only the owner of the homepage can edit it.

the owner of the homepage can add the bio for the homepage. for example, the owner can write in the bio "hi, i am looking for special shoes, i like old movies, send me offers if you have any". the content of the bio is not limited.

the homepage includes:
- the user listed items for sale
- if there is a live auction, view the highest offer of this auction
- reviews of past items that the user sold, and average rating based on the other users who bought the items(only the user that bought the item can review the item).
- the owner and only the owner can see the messages and all his active conversations at his homepage, whether they are about items the user is selling or items the user is bidding on. 
- the owner can reply to the buyer's messages from his homepage.
after listing an item, redirect the user to his homepage, and show a confirmation message that the item was listed successfully.
